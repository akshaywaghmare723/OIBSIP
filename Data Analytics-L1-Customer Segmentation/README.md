# 🛍️ Customer Segmentation Analysis

## 📌 Project Overview

This project performs customer segmentation analysis on e-commerce transaction data using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering.

## 🎯 Project Objective

The objective is to segment customers based on their purchasing behaviour and identify customer groups that can be targeted with suitable marketing strategies.

## 🛠️ Tools Used

- 🐍 Python
- 🐼 Pandas
- 🤖 Scikit-learn
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook

## 🔍 Analysis Performed

- 🔎 Data inspection and cleaning
- 📅 RFM analysis
- 🔄 Recency, Frequency and Monetary feature creation
- 📏 Data standardization using StandardScaler
- 🎯 K-Means clustering
- 📉 Elbow Method for selecting optimal clusters
- 📊 Cluster visualization
- 👥 Cluster profiling
- 📊 Customer count by cluster
- 💡 Marketing recommendations

## 📊 Key Insights

- 👥 Customers were divided into four distinct segments using K-Means clustering.
- 🛒 The segments show different purchasing behaviour based on Recency, Frequency and Monetary values.
- 💰 Cluster profiles can help identify valuable, frequent and inactive customer groups.

## 💡 Marketing Recommendations

- ⭐ Target high-value customers with premium offers and loyalty rewards.
- 🔄 Provide special discounts to frequent customers to encourage repeat purchases.
- 📢 Use personalized campaigns for customers who have not purchased recently.
- 🎯 Create targeted promotions based on the purchasing behaviour of each customer segment.

## 📂 Dataset

UCI Online Retail transaction dataset was used for this analysis.

## 📁 Project Structure

- 📓 Customer_Segmentation_Analysis.ipynb - Jupyter Notebook containing the complete analysis.
- 📊 Online Retail.xlsx - Dataset used for customer segmentation.

## ✅ Conclusion

Customer segmentation helps businesses understand different customer groups and create targeted marketing strategies, personalized offers and customer retention campaigns.
